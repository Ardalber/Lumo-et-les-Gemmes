# Lumo et les Gemmes

Jeu de plateforme 2D : traverse le niveau jusqu'au drapeau en ramassant les gemmes et en écrasant les Grognons.

Fait avec **Godot 4.7**.

**Jouer dans le navigateur (ordinateur ou téléphone) : https://ardalber.github.io/Lumo-et-les-Gemmes/**

- **Lancer en un clic** : ouvre `JOUER.html`.
- **Installer sur le téléphone** : au lancement, choisis « Installer sur le téléphone » (ou dans Chrome : menu ⋮ → Ajouter à l'écran d'accueil).
- **Ouvrir dans Godot** : Importer → `project.godot` → F5.
- **Règles et commandes** : voir `LISEZMOI.txt`.

## Mettre à jour la version Web

Dans Godot : Projet → Exporter → Web → Exporter le projet (vers `docs/index.html`), puis pousse sur GitHub.
